Hutch’s RV Park is my family’s park in Searcy, Arkansas. I drew the original layout of the park, designed the brand, and built the website my brothers run it with. It runs on Next.js with a Git-backed editor, so they can change deals and events without calling me.

The logo and the colors came first, and then the site that carries them. The content lives in Git behind a visual editor, so a deal or an event is a form, not a code change. The map of the park started as my own drawings of the layout.
