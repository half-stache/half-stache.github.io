# Sam Hutcherson

I'm a mechanical engineer by degree and a software developer by trade. I started reading obsessively in second grade and never stopped, which turned out to be most of the job. In engineering school I wrote stress and strain programs that classmates copied onto their TI-84s, graduated valedictorian and summa cum laude, and won a Startup Junkie healthcare boot camp with a dermatology app idea. After school I was an account manager at my family's insurance agency and set out to automate myself out of the job. The filing system I built there saves each account manager thirty to sixty minutes a day, and I still work on it. Today I run Hutchware LLC, a one-person studio, and build iOS apps, websites for small businesses, and a hydrology model for the Little Red River. I've released music since I was eighteen, first as 2NDSAMUEL and now under my own name.

## Work

- [VectorShield](https://vectorshield.app): an iOS and Apple Watch app for people with alpha-gal syndrome. It scans products, checks medications against FDA data, and finds safe food, tuned to one of four sensitivity levels. A Chrome extension does the same on retail sites.
- [LavaRise](https://apps.apple.com/us/app/lavarise/id6759515609): a pixel-art climbing game for iPhone, 100 levels across 10 chapters.
- Riverstock: a hydrology model of the Little Red River below Greers Ferry Dam that predicts conditions at each access point. The model and data pipeline are built; the API and apps are next.
- [Hutch's RV Park](https://hutchsrv.com): website, brand, and content system for my family's RV park in Searcy, Arkansas.
- [Elrod Construction & Services](https://elrodconstructionservices.com): website, logo, and hero video for a home builder in Texarkana.
